# MAHI! — Dark interactive creative CV for KYOK

A dark, retro, hand-drawn editorial portfolio built with plain HTML, CSS and JavaScript. All illustrations are inline SVG or CSS doodles — **no real photos or external photo assets are used**.

## Files
- `index.html` — site content and hand-drawn SVG illustrations
- `style.css` — dark theme, layouts, doodles, animation and responsive styling
- `script.js` — interactive project cards, vinyl animation, navigation state and toast messages
- `resume-checklist.md` — personalisation checklist

## Interactive details
- Click the vinyl record to spin/pause it.
- Click any project card to open its concept details.
- Navigation highlights the section you're viewing.
- Layout adapts for mobile and desktop.
- Reduced-motion settings are respected.

## Preview locally
Open `index.html` in your browser. The Google Fonts are online fonts; if you're offline, the site falls back to system fonts.

## Publish with GitHub Pages
1. Create a new GitHub repository (for example, `kyok-creative-cv`).
2. Upload the files in this folder to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. Wait for GitHub Pages to publish your site.

## Before applying
Replace `YOUR.EMAIL@example.com`, add your real social links, fill in your previous social media role and dates, confirm your debate dates, and list only tools you genuinely use. The portfolio concepts are labelled as self-initiated work rather than commissioned projects.
